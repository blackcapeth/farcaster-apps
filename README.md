# farcaster-apps

Landing page for three Farcaster mini apps: TodayVibe, Number Guess Battle, and World Cup 2026 picks.

## Live site

The page is live at:

https://farcaster-apps.vercel.app

https://blackcapeth.github.io/farcaster-apps/

Each card opens the matching Farcaster mini app:

TodayVibe: https://farcaster.xyz/miniapps/WIMT4asEwfzP/todayvibe

Number Guess Battle: https://farcaster.xyz/miniapps/OILJnpCUspKY/number-guess-battle

World Cup 2026: https://farcaster.xyz/miniapps/ORPbWE8oJlak/world-cup-2026

## What the apps do

TodayVibe gives a daily vibe reading.

Number Guess Battle is a multiplayer number guessing game.

World Cup 2026 is a predictions app for the 2026 World Cup.

## How to run locally

The site is a single static `index.html` file. Clone the repository and open that file in a browser:

```
git clone https://github.com/blackcapeth/farcaster-apps.git
cd farcaster-apps
```

Then open `index.html` in your browser, or serve the folder with any static file server.
